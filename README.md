# Sleeping Timer

Android app that switches on Do Not Disturb for a chosen time and puts your previous
settings back when the time is up.

Modes: Silent (total silence), Do Not Disturb (your own priority settings) and
Meditation (music/media only; calls, alarms and notifications blocked).
Duration: 15 minutes to 6 hours, or until you turn it off.

The APK is built automatically by GitHub Actions: open the Actions tab, pick the latest
run and download the `sleeping-timer-apk` artifact.

First run: press START, then switch on "Sleeping Timer" under Do Not Disturb access.
